# 차곡 CLI·TUI 사용법 · 0.5.8

## 시작

배포 ZIP을 압축 해제하면 `Chagok-v0.5.8.exe` 하나가 있습니다. 더블 클릭하거나 인수 없이 실행하면 GUI가 열립니다. .NET SDK 설치 없이 실행할 수 있습니다. PowerShell에서 압축 해제한 폴더로 이동한 뒤 사용하세요. PATH를 자동 변경하지 않으므로 현재 폴더의 실행 파일 앞에 `./` 또는 `.\`를 붙입니다.

```powershell
.\Chagok-v0.5.8.exe tui          # 방향키로 쓰는 TUI
.\Chagok-v0.5.8.exe help         # 전체 명령 도움말
.\Chagok-v0.5.8.exe version
```

GUI·CLI·TUI는 `%LOCALAPPDATA%\FileOrganizer`의 같은 설정과 기록을 사용합니다. 설정 형식은 버전 1을 유지하므로 등록된 폴더·규칙·테마·창 닫기 설정을 이어 사용합니다. 터미널에서 변경한 GUI 테마·닫기 설정은 다음 GUI 실행 때 적용합니다. TUI는 터미널 색을 사용하며 선택 항목은 `>`, 현재 영역은 `▶`로 표시합니다. 폴더·규칙·조건·목적지가 같은 화면에 표시됩니다. 최소 창 크기는 60열 × 24줄이며, 권장 크기는 80열 × 24줄 이상입니다. 작은 창에서는 크기 조정 안내를 표시하고 실행을 기다립니다. 너비가 80열보다 작으면 선택 영역의 목록을 표시하며 Tab으로 전환합니다.

**한 번에 하나만 실행합니다.** GUI가 트레이에 남아 있거나 TUI·watch가 실행 중이면 다른 클라이언트는 종료 코드 3으로 거부됩니다. GUI 트레이의 ‘종료’, TUI의 Q, watch의 Q 또는 Ctrl+C로 기존 세션을 끝낸 뒤 전환하세요. 이 버전은 두 앱을 동시에 열어 IPC로 설정을 동기화하는 구조가 아닙니다. 이전 GUI도 같은 Windows mutex를 확인하므로 같은 세션에서 충돌을 막습니다. 여러 로그인 세션에서도 0.5.8은 데이터 폴더 잠금을 함께 확인합니다.

`session.lock`은 실행 중 열린 핸들로 잠급니다. 파일 자체가 남아 있는 것은 정상입니다. 잠금 파일을 직접 지우지 마세요. OS가 프로세스 핸들을 해제하면 비정상 종료 후에도 재실행할 수 있습니다. 실행 파일이나 데이터 폴더를 강제로 삭제해 잠금을 우회하지 마세요.

다른 설정으로 시험하려면 `--data-dir C:\Study\ChagokData`를 지정합니다. 기존 설정을 복사하지 않으면 빈 설정에서 시작합니다. 테스트 데이터만 별도로 사용하는 옵션이며 GUI의 기본 저장 위치를 바꾸지는 않습니다. Windows의 기존 앱 잠금은 별도 데이터 폴더를 사용해도 함께 확인합니다.

## TUI 단축키

| 화면 | 키 | 동작 |
|---|---|---|
| 대시보드 | Tab / ← / → | 폴더·규칙 영역 전환 |
| 폴더 | ↑↓, Enter | 폴더 선택 후 규칙 영역으로 이동 |
| 폴더 | F / E / C / D | 폴더 추가 / 편집 / 설정·규칙 복제 / 등록 제거 |
| 공통 | R / A | 선택 규칙 검사 / 폴더 전체 검사 |
| 공통 | N / H / S / W | 규칙 추가 / 기록 / 설정 / 프로그램 감지 |
| 규칙 | N / E / D | 추가 / 편집 / 제거 |
| 규칙 | Space | 사용 여부 전환. 이동을 시작하지 않음 |
| 규칙 | R 또는 Enter / A | 선택 규칙 검사 / 폴더의 켜진 규칙 전체 검사 |
| 미리보기 | ↑↓ / Space | 항목 이동 / 선택 토글 |
| 미리보기 | A / U | 모든 페이지의 실행 가능 항목 선택 / 전체 해제 |
| 미리보기·결과 | N / P / I | 다음 페이지 / 이전 페이지 / 전체 경로·상세 |
| 미리보기 | Enter, Y | 전체 선택 개수·기존 파일 교체 개수 확인 후 실행 |
| 기록 | ↑↓ / Enter | 기록 선택 / 전체 경로와 이유 확인 |
| 감지 | Enter / D / Q | 첫 확인 요청 검사 / 첫 요청 무시 / 감지 종료 |
| 대시보드 | F / I / Q | 새 폴더 / 전체 경로 / 종료 |
| 대시보드 | Esc | 규칙 영역에서 폴더 영역으로, 폴더 영역에서는 종료 |
| 일반 목록 | Esc / Q | 이전 화면 또는 TUI 종료 |
| 작업 중 | Ctrl+C | 안전한 중단을 요청하고 터미널 앱 종료 |

TUI 상단에는 블록 문자로 채운 차곡 심볼과 CHAGOK 픽셀 로고를 표시합니다. 그림 파일이나 이모지에 의존하지 않습니다. N은 현재 영역과 무관하게 선택 폴더의 규칙을 추가하고, 저장하면 새 규칙을 선택해 표시 범위를 옮깁니다. 규칙 개수와 저장 완료 문구도 확인할 수 있습니다. 취소하면 기존 선택과 설정을 유지합니다.

R은 어느 영역에서도 선택 규칙만 검사합니다. A는 폴더의 켜진 규칙 전체를 검사합니다. 미리보기 상단에 검사 범위를 표시하며 이동 전 확인을 유지합니다. 꺼진 규칙은 Space로 켜야 검사할 수 있습니다.

폴더·규칙 폼은 항목 목록에서 바로 수정합니다. 텍스트 입력창의 Esc 또는 /cancel + Enter는 해당 항목만 취소합니다. 빈 Enter는 기존 값 유지, `/clear`는 비우기입니다. 선택값은 ←→로 바꿉니다. 목록에서 S를 누르면 검토 화면을 열고 Y로 저장합니다. 검토 취소는 초안을 유지하고 항목 목록으로 돌아갑니다. 전체 폼 취소는 목록에서 Esc입니다. 경로는 직접 입력하며 I로 전체 값을 볼 수 있습니다.

검사 결과는 100건 단위입니다. 한 페이지가 화면보다 길면 방향키로 계속 이동합니다. 페이지 이동 후 선택도 유지됩니다. 파일 이동 후에는 결과 화면을 보여주며 I로 원본·대상·판단 이유·처리 결과를 확인할 수 있습니다. Ctrl+C로 앱을 끝내도 이미 완료한 이동은 되돌리지 않습니다.

## CLI로 PDF 정리하기

먼저 실제 파일 대신 복사본으로 시험하세요. 경로·이름에 공백이 있으면 따옴표로 감쌉니다. 이름이 중복되면 목록에 표시된 전체 ID를 사용해야 합니다.

```powershell
.\Chagok-v0.5.8.exe folders add --name 다운로드 --path "C:\Users\사용자\Downloads"
.\Chagok-v0.5.8.exe folders list
.\Chagok-v0.5.8.exe rules add --folder 다운로드 --name "PDF 정리" --destination "D:\정리\PDF" --match any --extensions .pdf
.\Chagok-v0.5.8.exe rules list --folder 다운로드
.\Chagok-v0.5.8.exe scan --folder 다운로드 --rule "PDF 정리"
.\Chagok-v0.5.8.exe run --folder 다운로드 --rule "PDF 정리"
```

`scan`은 파일을 이동하지 않습니다. `run`은 **새로 검사**하고 첫 페이지와 전체 개수를 표시한 뒤 `yes`를 입력받습니다. 이전 scan의 선택·계획을 가져오는 명령은 아닙니다. 파일 선택은 TUI를 사용하세요. CLI run은 새 계획의 모든 실행 가능 항목을 대상으로 합니다. 표시된 100건만 실행하는 것이 아닙니다.

```powershell
.\Chagok-v0.5.8.exe scan --folder 다운로드 --page 2 --json
.\Chagok-v0.5.8.exe run --folder 다운로드 --rule "PDF 정리" --yes --json
```

`--yes`는 전체 범위 실행에 대한 승인입니다. 자동화·리디렉션·JSON 실행에는 이 옵션이 필요하며, 없으면 파일을 옮기지 않고 종료 코드 2를 반환합니다. 실행 전에 파일 상태를 다시 확인하고 기존 Executor의 복사·검증·원본 보존 정책을 유지합니다. `--json`은 stdout에 결과 JSON, 오류는 stderr에 오류 JSON을 출력합니다. 일반 명령은 한 JSON 객체/배열이며 watch는 이벤트마다 한 줄의 JSON을 출력합니다.

### 주요 옵션

| 대상 | 옵션 |
|---|---|
| 파일명 | `--match any` / `contains` / `starts` / `glob`, `--pattern` |
| 확장자 | `--extensions .pdf,.jpg` (빈 값이면 전체) |
| 하위 폴더 | `--recursive on` / `off` |
| 이름 충돌 | `--conflict rename` / `replace` / `skip` |
| 목적지 생성 | `--create on` / `off` |
| 규칙 사용 | `--enabled on` / `off` |
| 폴더 제외 | `--exclude "C:\원본\제외1;C:\원본\제외2"` |
| 폴더·규칙 실행 조건 | `--trigger manual` / `start` / `stop`, `--program "C:\앱\tool.exe"`, `--mode confirm` / `auto` |

`folders update`, `rules update`는 지정한 값만 바꾸고 나머지는 유지합니다. 제외 폴더·프로그램 조건은 GUI와 같은 설정 필드에 저장합니다. 폴더 복제는 원본의 목적지를 그대로 유지하며 제외 경로를 새 원본의 같은 상대 위치로 옮깁니다.

```powershell
.\Chagok-v0.5.8.exe folders clone --folder 다운로드 --name "다른 자료" --path "E:\자료"
.\Chagok-v0.5.8.exe rules update --folder 다운로드 --rule "PDF 정리" --enabled off
.\Chagok-v0.5.8.exe folders update --folder 다운로드 --exclude "C:\Users\사용자\Downloads\보관"
.\Chagok-v0.5.8.exe rules remove --folder 다운로드 --rule "PDF 정리" --yes
.\Chagok-v0.5.8.exe folders remove --folder "다른 자료" --yes
.\Chagok-v0.5.8.exe settings set --theme dark --close tray --confirm-exit on
.\Chagok-v0.5.8.exe settings show
.\Chagok-v0.5.8.exe history --limit 20 --json
```

remove는 **등록 설정만 제거**합니다. 실제 원본 폴더·파일이나 이미 이동한 파일은 삭제하지 않습니다. 중복 옵션·오타·알 수 없는 값은 거부합니다. help에서 각 명령을 확인하세요.

## 프로그램 감지: watch

```powershell
.\Chagok-v0.5.8.exe rules update --folder 다운로드 --rule "PDF 정리" --enabled on --trigger stop --program "C:\앱\tool.exe" --mode confirm
.\Chagok-v0.5.8.exe watch --folder 다운로드
```

확인 모드는 요청을 보류합니다. --json을 사용하지 않는 대화형 터미널에서는 Enter로 목록을 열고 선택 후 이동합니다. 리디렉션에서는 확인 요청을 자동 실행하지 않으며 Ctrl+C로 watch를 끝낸 뒤 run 등으로 직접 처리해야 합니다. 확인 요청이 앞에 있으면 뒤의 자동 요청도 대기합니다.

자동 모드가 설정된 watch를 시작하면 파일 이동 가능성을 확인받습니다. 자동화로 시작하려면 `watch --yes --json`을 사용합니다. 저장한 자동 조건에 따라 확인 없이 파일을 옮길 수 있습니다. 대기 요청은 최대 100개이며 같은 규칙 집합의 반복 대기는 통합합니다. GUI와 같이 같은 이벤트에 폴더·규칙 조건이 겹치면 중복 포함하지 않습니다.

watch 또는 TUI 감지 화면이 실행 중인 동안만 감지합니다. 일반 TUI 메뉴에서는 자동 감지를 하지 않습니다. 기존 WMI·250ms 대체 감지·실제 EXE 경로 비교를 재사용합니다. 첫 실행본·마지막 종료 기준, 이미 실행 중인 앱을 새 시작으로 보지 않는 점, 짧은 실행 누락과 경로 권한 한계도 같습니다. 감지 진단·파일 처리 결과는 공통 history.jsonl에 기록합니다.

## 실행 파일 통합 방식

배포 EXE는 콘솔 실행 형식을 사용해 CLI의 파이프·종료 코드·명령 종료 대기를 유지합니다. GUI 경로에서만 FreeConsole로 콘솔을 분리합니다. 더블 클릭 시 Windows가 만든 콘솔이 잠깐 보일 수 있습니다. GUI는 터미널에서 인수 없이 실행해도 콘솔 연결이 분리되므로 CLI 작업에는 명령을 명시하세요. 탐색기의 --add-rule 요청은 기존 GUI 경로로 전달됩니다.

## 환경별 범위와 제한

- Windows x64 배포: GUI와 CLI·TUI. Windows 휴지통 교체와 프로그램 감지 코드는 공유합니다. 실제 Windows GUI↔터미널 전환, 키보드·배율·터미널 호환, WMI·휴지통은 Windows 테스트 PC에서 재검증해야 합니다.
- macOS 개발 환경: SDK로 터미널 프로젝트를 실행해 기본 파일 이동·설정·TUI를 검증할 수 있습니다. GUI·WMI 감지는 지원하지 않습니다. 휴지통 교체도 지원하지 않으므로 replace가 실패하면 기존 파일을 보존하며 영구 삭제하지 않습니다. 별도 macOS 실행 파일은 이번 Windows 배포에 포함하지 않습니다.
- 탐색기 메뉴 등록·해제와 트레이는 기존 GUI에서 관리합니다. 터미널의 auto-menu 설정 변경은 다음 GUI 실행 시 반영됩니다.
- 작업 중 강제 종료는 취소와 다릅니다. 파일 안전 검사를 유지해도 모든 전원·디스크 장애에서 복구를 보장하지는 않습니다. 복사본과 백업으로 시험하세요.
- 반환 코드: 0 성공, 1 오류, 2 인수·승인 필요, 3 다른 차곡 사용 중, 4 보류·원본 보존·경고 등 확인 필요, 130 취소. JSON 출력이 있더라도 종료 코드를 함께 확인하세요.

## 블록 로고와 색상

0.5.8 상단 로고는 █/▀/▄ 블록 문자로 앱 심볼과 CHAGOK을 표시합니다. 심볼과 글자는 청록색입니다. 실제 색과 글자 모양은 터미널 팔레트·폰트에 따라 달라집니다. 밝은 배경에서는 어두운 청록을 사용하며 본문은 원래 글자색을 유지합니다. NO_COLOR 환경 변수가 있으면 색을 끕니다. 권장 환경은 고정폭 글꼴을 사용하는 Windows Terminal입니다.

## 0.5.8 규칙 추가와 개별 실행

N으로 규칙을 추가하면 선택 검사 폴더 이름과 전체 경로를 먼저 표시하고 저장 확인에서도 반복합니다. 긴 경로는 줄을 바꿔 전체 표시합니다. Tab → ↑↓로 규칙 선택 → R 이 규칙만 검사 및 실행 → 미리보기에서 Enter → Y가 개별 이동 순서입니다. R은 왼쪽 영역에서도 현재 선택 규칙만 검사합니다. A는 폴더 전체입니다.

TUI 상단은 굵은 획과 청록 단색을 사용합니다. 80열 미만은 심볼 없이 이름을 표시해 글자가 잘리지 않도록 합니다. GUI 아이콘은 이 변경의 대상이 아닙니다.

새 배포 실행 파일은 Chagok-v0.5.8.exe입니다. 시작 인수·설정 경로는 유지합니다. 내부 어셈블리와 개발 빌드 이름 Chagok은 유지하며 단일 파일 publish 결과에 버전을 붙입니다.

## 0.5.8 입력 중 돌아가기

폴더·규칙 텍스트 입력창의 Esc 또는 /cancel + Enter는 그 항목의 편집만 취소합니다. 폼 목록의 Esc는 전체 초안을 취소합니다. 설정 화면은 Esc로 변경을 취소합니다. Ctrl+C는 앱 종료용입니다.

좌우 방향키·Home/End로 커서를 옮기고 Delete/Backspace로 수정합니다. 긴 경로는 입력 중 가로로 이동합니다. Enter는 해당 칸의 입력 완료이며 빈 입력은 기존 값을 유지합니다.

## 0.5.8 기능 설명

메인과 미리보기에서 F1 또는 ?를 누르면 현재 영역과 관련된 기능 설명을 엽니다. ←→로 기능을 바꾸고 ↑↓/PgUp/PgDn으로 읽습니다. Esc는 선택·검사 결과를 유지하고 원래 화면으로 돌아갑니다. 입력 폼에서는 기존 Esc 취소를 사용합니다.

```powershell
.\Chagok-v0.5.8.exe help
.\Chagok-v0.5.8.exe help run
.\Chagok-v0.5.8.exe rules add --help
.\Chagok-v0.5.8.exe help --json
.\Chagok-v0.5.8.exe help rules add --json
```

JSON은 schemaVersion·commands·commonOptions·safety·exitCodes를 포함합니다. 명령에는 usage·effects·confirmation·windowsOnly·options·examples·notes가 있습니다. 옵션의 type·required·default·choices를 확인하세요. null 기본값은 해당 문맥의 기존 값/명령 기본값을 따르며 notes를 함께 읽어야 합니다.

같은 정보는 docs/cli-reference.json으로도 제공합니다. help/version은 설정을 읽거나 잠금을 획득하지 않습니다. 다른 명령의 독점 실행 규칙은 유지됩니다. AI 기능을 앱에 연결하는 기능이 아니라 사람이거나 외부 AI가 CLI 사용법을 읽을 수 있게 하는 설명입니다.

상단 심볼과 CHAGOK 이름은 D안 점 문자입니다. 청록/파랑은 터미널 팔레트를 따릅니다. NO_COLOR와 밝은 배경에 대한 대응은 유지합니다.


폴더 또는 규칙 영역에서 I를 누르면 해당 상세 화면을 엽니다. ↑↓, PgUp/PgDn, Home/End로 스크롤하고 Esc 또는 Enter로 목록에 돌아갑니다. F1/?는 해당 기능 설명입니다.


폴더/규칙 항목은 기본 정보·파일 조건/제외 폴더·이동 동작·실행 조건으로 나뉘며 순서와 관계없이 수정할 수 있습니다.


설정(S)은 항목 선택형입니다. ↑↓/Tab 또는 1~4로 원하는 항목을 바로 선택하고 ←→/Enter/Space로 값을 바꿉니다. S는 저장, Esc는 변경 취소입니다. 설정 화면의 GUI 테마는 TUI 색상을 바꾸지 않습니다.


0.5.8부터 폴더/규칙 생성·편집·복제도 목록형입니다. 폴더/규칙 폼은 ↑↓/Tab/1~9로 항목 선택, Enter/E 텍스트 편집, ←→ 선택값 변경, I 전체 값 확인입니다. S 검토 후 Y 저장. 입력칸 Esc는 항목 취소, 목록 Esc는 전체 폼 취소입니다. 검토 화면에서 Esc를 누르면 초안을 유지한 채 항목 목록으로 돌아갑니다. 사용하지 않는 조건의 값은 보존합니다.

## 최근 이동 위치와 규칙명 폴더

`folders update --folder 다운로드 --recent-destinations on`으로 해당 검사 폴더의 최근 위치 표시·기록을 켭니다. 규칙 저장에 성공한 기본 이동 위치만 최신 10개를 보관합니다. off는 기록을 삭제하지 않고 표시·새 기록을 중단합니다. TUI 규칙 입력의 이동 위치 도우미에서 최근 위치를 ←→로 고를 수 있습니다.

`rules add --folder 다운로드 --name PDF --destination D:\정리 --match any --extensions .pdf --append-rule-name on`은 `D:\정리\PDF`로 이동합니다. 기본 위치는 `D:\정리`로 보관하므로 규칙명은 중복해서 붙지 않습니다. 이 옵션을 켜면 `--create off`여도 실행 때 최종 폴더를 생성합니다. 최종 경로는 TUI 검토와 CLI scan의 Target에서 확인하세요.

### 새 규칙 기본값과 항목별 설명

TUI에서 새 규칙을 만들 때 최근 위치 표시가 켜져 있으면 가장 최근 기본 이동 위치를 미리 채웁니다. 기존 규칙 편집에는 적용하지 않습니다. 최근 위치 항목도 계속 사용할 수 있습니다.

폴더·규칙 항목을 고르면 아래에 기능과 연계 옵션을 설명합니다. I를 누르면 전체 값과 설명을 스크롤해 읽습니다. ‘규칙명 폴더 사용’이 켜져 자동 생성이 강제로 적용되는 경우 ‘켜짐 · 자동 적용’과 이유를 보여줍니다.
