# 차곡 0.5.0 CLI·TUI

- 기존 GUI 설정(JSON 버전 1)·기록·Planner·DiskPlanStore·Executor를 재사용한다.
- Chagok.exe 하나를 배포한다. 인수 없음/--add-rule은 GUI, tui는 대화형 TUI, 나머지는 CLI로 전달한다. 콘솔 서브시스템+GUI 진입 시 FreeConsole을 사용한다. GUI 더블 클릭의 일시 콘솔 표시 가능성은 Windows에서 확인한다. 개발·중립 플랫폼 검증용 터미널 프로젝트는 유지하지만 별도 EXE로 배포하지 않는다.
- 설정을 읽기 전 공통 SessionLease를 획득하고 종료까지 보유한다. Windows 기존 Local mutex 이름도 유지한다. GUI 트레이 상주와 TUI·watch도 독점 세션이다. 한 번에 하나만 실행하도록 하며, IPC로 다른 앱의 작업을 강제로 종료하지 않는다.
- settings.json을 읽기 전 잠금을 획득하므로 낡은 설정으로 덮어쓰지 않는다. 잠금 파일은 삭제하지 않으며 OS 핸들이 닫히면 다시 획득할 수 있다. 서로 다른 Windows 세션도 같은 데이터 폴더 파일 잠금을 확인한다.
- help/version/path는 잠금 없이 볼 수 있다. 명령의 종료 코드·JSON 출력·잘못된 인수 거부를 제공한다.
- 수동 scan은 이동하지 않는다. run은 새로 검사한 범위를 표시한 뒤 확인한다. 리디렉션에서는 --yes 없이는 실행·삭제하지 않는다. --yes는 모든 실행 가능 항목에 대한 명시적 승인이다.
- TUI는 방향키·Enter·Space와 단축키를 사용한다. 페이지 선택을 유지하고 실행 전 선택 개수·교체 개수로 확인한다. 터미널에서 파일 경로는 직접 입력한다.
- Windows 프로그램 감지는 기존 구현을 재사용하며 watch 화면/명령이 실행 중일 때만 동작한다. 확인 모드는 요청을 보류하며 자동 모드만 자동 실행한다. 조회 실패·이벤트 누락 한계는 GUI와 같다.
- Windows 휴지통 처리도 재사용한다. 비 Windows 환경에서는 교체 시 휴지통이 지원되지 않으므로 실패로 원본을 보존하며 영구 삭제하지 않는다. Windows 전용 탐색기 메뉴·트레이는 GUI에서 관리한다.
- 터미널 출력의 파일명·설정 문자열에서 제어 문자를 제거해 화면 명령으로 해석되지 않게 한다. GUI 스타일·파일 이동 안전 로직은 변경하지 않는다.

- TUI 대시보드는 폴더와 규칙을 나란히 표시하고 선택 규칙의 조건·목적지를 고정 표시한다. Tab으로 영역을 전환하고 80열 미만에서는 선택 영역 목록으로 전환한다. 결과는 디스크 페이지·선택·실행 전 확인을 유지한다. 진행 막대는 파일 수 기준이며 현재 파일의 단계/bytes와 구분한다. 결과 목록에도 완료 요약을 유지한다.

- 0.5.0: 문자 심볼을 상단에 표시한다. F/N을 폴더/규칙 추가로 고정하며 규칙 저장 후 새 ID를 최신 설정에서 선택한다. R은 현재 영역과 무관하게 선택 규칙 검사, A는 폴더 전체다. 검사 범위를 미리보기에 표시한다.

## 0.8.0 방식별 시작 경로

시작 메뉴는 등록 폴더 기본값과 1 기존 규칙 / 2 기준 폴더를 제공한다. 기존 규칙의 R/A/F/N과 검사/실행은 유지한다. O/폴더 영역 Esc는 시작으로 복귀한다. 기준 폴더의 임시 원본 입력은 등록·제외·규칙 설정을 변경하지 않는다. 결과의 Tab 파일/그룹, N/P 100건 페이지, F 상태필터, I 전체값, D 목적지, H 보류, W 경고, V 계획 검토를 제공한다. 모든 실제 이동은 공통 미리보기에서 전체 선택 수·교체 수로 재확인한다. 변경 후의 TUI 명세는 terminal-guide.md와 CLI help tui에 함께 반영한다.
