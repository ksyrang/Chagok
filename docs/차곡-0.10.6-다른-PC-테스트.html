CHAGOK · WINDOWS TEST GUIDE

다른 PC에서 차곡 테스트하기

설치부터 기준 폴더 분석, 이동 계획, 실제 결과까지 순서대로 확인합니다. 아래 체크는 직접 확인한 뒤 표시하세요.

버전 0.10.6Windows x64테스트 파일 6개

테스트 순서

01 준비하기 02 설치와 실행 03 테스트 파일 만들기 04 기준 폴더 분석 05 제안과 이동 계획 06 실제 이동 확인 07 추가 확인 08 결과 남기기
01

준비하기

다른 Windows PC에서 이 문서를 열고 아래 설치 파일을 다운로드합니다. 인터넷은 다운로드할 때만 필요합니다.

0.10.6 설치 파일 다운로드 릴리스 페이지 보기
테스트 전용 폴더를 사용하세요. 실제 업무 파일이나 기존 다운로드 폴더는 선택하지 않습니다. 테스트가 끝날 때까지 테스트 폴더를 지우지 마세요.

0.10.6은 테스트 릴리스입니다. 새 화면과 이동 흐름을 이 PC에서 직접 확인하기 위한 안내입니다.

02

설치하고 실행하기

  1. 다운로드한 Chagok-v0.10.6-setup-win-x64.exe를 실행합니다.
  2. 설치 위치와 바로가기·PATH 옵션을 확인하고 설치합니다.
  3. 차곡을 실행합니다. 이전 차곡이 실행 중이면 트레이에서도 종료한 뒤 다시 시도합니다.
터미널 명령도 확인하려면: PATH 등록을 선택한 경우 PowerShell을 완전히 닫았다가 다시 열고 chagok version을 입력합니다. 0.10.6이 표시되는지 확인합니다. GUI가 트레이에 있으면 파일 작업 명령은 별도 단일 실행 제한을 받을 수 있습니다.
03

테스트 폴더와 파일 만들기

바탕화면에 새 폴더 차곡 테스트를 만들고 다음 구조를 그대로 준비합니다. 검사할 파일과 정리된 기준은 서로 다른 폴더여야 합니다.

차곡 테스트/
├─ 검사할 파일/
│  ├─ 거래처A_견적.txt
│  ├─ 거래처A_거래처B_회의.txt
│  ├─ [신규C] 초안.txt
│  ├─ [신규C] 최종.txt
│  ├─ [중복D][중복E] 자료.txt
│  └─ 일반메모.txt
└─ 정리된 기준/
   ├─ 거래처A/
   └─ 거래처B/

빈 텍스트 파일 6개면 충분합니다. 탐색기에서 파일 확장명이 숨겨져 있다면 보기 → 표시 → 파일 확장명을 켜고 이름을 확인하세요. 파일 안에는 구별할 수 있는 짧은 내용을 적어도 됩니다.

04

기준 폴더로 분석하기

  1. 첫 화면에서 기준 폴더 선택하기를 누릅니다.
  2. 검사할 폴더에 검사할 파일을 선택합니다.
  3. 정리된 기준 폴더에 정리된 기준을 선택하고 하위 폴더 가져오기를 누릅니다.
  4. 거래처A·거래처B의 검색어가 각각 폴더명인지 확인합니다. 검색 방법은 파일명에 포함, 그룹 기준은 대괄호 [ ]로 둡니다.
  5. 파일 분석을 누릅니다.

분석 직후 기대 결과

구분예상이유
이동 폴더 지정1개거래처A 견적 파일이 기존 폴더 하나와 일치합니다.
새 폴더 제안2개두 파일의 대괄호 안 값이 신규C로 같습니다.
기존 폴더 선택 필요1개회의 파일이 거래처A와 거래처B에 모두 맞습니다.
여러 그룹 선택 필요1개자료 파일에 중복D와 중복E가 모두 있습니다.
제안 없음1개일반메모에는 기존 폴더 검색어나 대괄호 그룹이 없습니다.

개수가 다르면 파일 이름, 검색어와 대괄호 기준을 먼저 확인하세요. 실제 결과가 다르면 기록하고 다음 실행은 잠시 멈춰 주세요.

05

제안과 이동 계획 확인하기

  1. 새 폴더 제안에서 신규C를 선택합니다. 아래 파일 목록에서 초안과 최종 두 파일을 확인합니다.
  2. 새 폴더 이름이 신규C인지 확인하고 선택한 제안 적용을 누릅니다. 확인 창에서도 폴더와 파일 수를 확인합니다.
  3. 파일 확인과 개별 지정 필터에서 기존 폴더 선택 필요를 고릅니다. 회의 파일을 선택하고 기존 폴더 사용 → 거래처B → 선택 파일에 적용을 누릅니다.
  4. 여러 그룹 선택 필요와 제안 없는 파일 필터를 각각 확인합니다. 두 파일은 이번 테스트에서 지정하지 않습니다.
  5. 이동 계획 검토를 누릅니다. 아직 실행하지 말고 파일과 목적지를 확인합니다.
계획이 다르면 실행하지 마세요. 표시된 파일명·이동할 폴더·개수와 화면을 기록해 주세요.
06

실제 이동 결과 확인하기

앞 단계가 모두 예상과 같고 테스트용 파일이 맞을 때만 진행합니다. 이동 계획에서 선택된 파일 4개와 목적지를 다시 확인한 뒤 선택 4개 실행을 누릅니다.

완료 문구만으로 이동 성공을 판단하지 말고, 탐색기에서 원본과 대상 위치를 함께 확인하세요.

07

여유가 있으면 추가 확인

다음은 별도 테스트입니다. 이미 이동한 파일로 결과를 다시 분석하면 앞의 개수는 달라집니다. 새 테스트 폴더를 만들어 확인하세요.

08

결과 남기기

문제가 생기면 어느 단계에서 무엇을 했는지와 실제 화면을 함께 남겨 주세요. 오류 창이 있다면 문구를 그대로 적으면 원인을 확인하는 데 도움이 됩니다.

체크와 메모는 이 브라우저에서만 저장됩니다. 파일을 다른 PC로 옮겨도 체크 상태는 함께 옮겨지지 않습니다. 인쇄하거나 PDF로 저장하면 결과를 전달하기 편합니다.

이 브라우저에서 저장소를 사용할 수 없어 체크와 메모가 새로고침 후 유지되지 않습니다.

이 문서는 차곡 0.10.6 테스트용입니다. 실제 앱의 동작을 대신 실행하지 않습니다.
