# Forel 참조 범위와 출처 점검

점검일: 2026-10-19

## 결과

확인한 범위에서는 Forel 코드·이미지를 차곡에 직접 복사해 사용했다는 근거를 발견하지 못했다. 이 결과는 독립 개발이나 법적 비침해를 보증하지 않는다.

개발 당시 Forel의 폴더·규칙 관리 방식, 소스 코드 일부와 화면을 분석한 기록이 있다. 따라서 Forel 코드를 전혀 보지 않은 개발이라고 설명하지 않는다. README는 영감을 받은 구성과 공식·제휴 관계가 없다는 사실을 밝히고, 코드의 독립성을 단정하는 표현은 사용하지 않는다.

이미지 비교와 별도로 Forel의 초록색 식물형 아이콘·앱 화면과 차곡의 남색 폴더 심볼·승인 시안을 시각적으로 확인했다. 비교용 Forel 사본·이미지·연락처·대화 원문·비교용 썸네일은 차곡 저장소에 추가하지 않았다.

## 차곡 자산과 외부 구성 요소

- `assets/branding/chagok-approved-board.png`: 사용자가 승인한 초기 생성 시안 원본과 SHA256 일치.
- `assets/branding/chagok-approved-board-v2.png`: 사용자가 첨부한 새 시안 원본과 SHA256 일치.
- 앱 아이콘은 사용자 시안을 기준으로 이미지 생성 도구로 정리한 파생 자산이며, PNG·ICO·탐색기 로고로 변환했다. 자세한 생성 경위는 [브랜딩 기록](../assets/branding/README.md)을 따른다.
- TUI의 심볼과 CHAGOK 이름은 문자 데이터다. Forel의 이미지 파일을 실행 중 불러오지 않는다.
- 차곡은 .NET/WPF와 `Microsoft.Data.Sqlite`, `System.Management` 등을 사용한다. 네이티브 탐색기 확장에는 MinGW-w64 런타임 관련 고지가 포함되어 있다. 이는 Forel 재사용과 별개인 외부 구성 요소다. [기존 고지](../src/Chagok.Windows/Assets/Shell/ShellExtension-LICENSES.txt)를 유지했다.

## 해석의 한계

해시·행·연속 토큰 불일치는 번역, 크게 수정된 코드, 수작업 재작성, 누락된 과거 이력이나 외부 자료의 유입을 배제하는 증거가 아니다. C#과 Swift라는 언어 차이만으로 독립성을 증명할 수도 없다. 이미지 정규화 비교도 임의 편집·벡터 재작성·스타일 모방 전체를 검출하지 못한다.

폴더 → 규칙 → 조건·동작이라는 참고 범위와 코드·이미지의 직접 재사용을 구분해 기록했다. UI의 창작적 표현이나 상표·저작권 침해 여부, 다른 제3자 자산 및 AI 생성 이미지의 전체 권리 관계는 이 검사만으로 확정하지 않는다. 과거 배포 ZIP·SDK·NuGet 캐시 전체에 대한 라이선스 감사도 이번 범위가 아니다.

Forel의 소스 라이선스는 [GPL-3.0-or-later](https://github.com/lab421/forel/blob/cda2557165093437e1d09be0257fdcc845c7ab11/LICENSE)이며, 브랜드에 관한 정책은 [TRADEMARKS.md](https://github.com/lab421/forel/blob/cda2557165093437e1d09be0257fdcc845c7ab11/TRADEMARKS.md)에 별도로 있다. 해당 문서는 사실에 근거한 언급을 허용하고 공식·제휴 관계로 오해시키는 사용을 제한한다. 이 점검을 이유로 차곡에 GPL 의무가 없다고 법적으로 단정하거나, 허가받지 않은 브랜드 사용을 승인하지 않는다.
