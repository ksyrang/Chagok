# 차곡 화면과 피드백 스펙

현재 구현의 기준이다. 프로젝트의 작업 규칙은 `../AGENTS.md`, Windows에서 직접 확인할 절차는 `windows-test-guide.md`를 따른다.

## 화면 구조와 브랜드

왼쪽은 검사할 폴더, 본문은 선택 폴더의 규칙이다. ‘검사 및 실행’은 결과 확인 후 별도의 실행 버튼으로 이동을 시작하는 화면이다. 폴더 전체 검사와 개별 규칙 검사를 모두 제공한다. 결과 목록은 100건씩 표시하고, 전체 선택과 실행은 모든 페이지의 선택 상태를 기준으로 한다.

이름은 차곡 / Chagok, 제작자는 by ksyrang이다. 승인 시안 원본은 `../assets/branding/chagok-approved-board-v2.png`, 앱용 자산은 `../src/FileOrganizer.Windows/Assets`에 있다. 로고와 실행 파일·창·트레이 아이콘을 연결한다.

상단 앱 이름 옆에는 ‘규칙으로 파일을 차곡차곡’ 설명을 표시한다. 버전은 메인 화면에 표시하지 않고 설정의 앱 정보에서 실행 어셈블리의 실제 세 자리 버전을 `ver. 0.2.1` 형식으로 표시한다. 설정 버튼은 기어, 폴더 설정 버튼은 폴더 우상단에 기어를 겹친 벡터 아이콘을 사용한다. 아이콘 버튼에는 툴팁과 접근 가능한 이름을 제공한다. 데이터 폴더 열기는 설정의 앱 정보에 배치하며 기존 저장 경로를 연다. 이 버튼은 설정을 저장하거나 창을 닫지 않는다.

## 테마와 입력 컨트롤

라이트·다크·시스템을 제공한다. 시스템은 Windows 앱 테마를 따른다. 파생 편집 창, 목록, 입력칸, 버튼, 팝업, 비활성 상태까지 앱 색 리소스를 일관되게 사용한다. 실행 중 폴더 목록 잠금은 배경색을 바꾸지 않고 내용의 강조를 줄인다.

콤보 박스는 전체 테두리, 오른쪽 화살표, 선택 글자 공간이 분리되어야 한다. 펼친 목록은 해당 컨트롤을 기준으로 배치한다. 커스텀 내부 버튼에 기본 테마의 크기·정렬이 섞이지 않아야 한다.

폴더와 실행 파일 선택은 Windows 기본 대화상자를 사용한다. 취소는 입력을 변경하지 않는다. 직접 경로 입력도 제공한다. 입력칸과 버튼의 위쪽 위치가 같도록 공통 여백을 행에 둔다. 제외 폴더는 이름·전체 경로 표와 추가·제거 기능을 유지한다.

## 설정과 규칙 카드

상단 ‘설정’에서 테마, 닫기 버튼(X)의 동작, 종료 전 확인을 저장한다. 메인 화면의 테마 빠른 선택은 아이콘 버튼과 가로 아이콘 선택창으로 제공한다. 시스템은 모니터, 라이트는 해, 다크는 달을 사용한다. 시스템·라이트·다크 아이콘 버튼을 가로로 배치한다. 이름은 툴팁·접근 가능한 이름으로 제공한다. 현재 선택은 배경·테두리·라디오 선택 상태로 구분한다. Tab·Enter/Space로 열고 Tab·방향키로 이동, Enter/Space로 선택, Escape로 닫을 수 있어야 한다. 바깥 클릭으로 닫고 선택하면 적용 후 닫는다. 설정 창과 메인 아이콘의 값은 저장 후 일치해야 한다. 앱 설정 변경만으로 현재 검사 결과나 대기 요청을 지우지 않는다.

창 닫기의 기본값은 ‘창만 닫고 백그라운드에서 실행’이다. ‘프로그램 종료’를 선택하면 확인창을 표시한다. 확인창의 ‘다시 묻지 않기’는 종료를 확정한 경우에만 저장한다. 취소·Escape·확인창 X는 종료와 확인 생략을 적용하지 않는다. 설정에서 확인창을 다시 켤 수 있다. 트레이 메뉴의 명시적인 ‘종료’는 기존처럼 별도 확인 없이 종료를 요청한다.

작업 중 종료 요청은 새 감지 작업을 차단하고 현재 작업을 안전하게 중단한 뒤 실제 종료한다. 이미 완료한 이동은 되돌리지 않는다. 창 닫기 안내는 저장한 동작에 맞춰 표시한다. 설정 저장이 실패하면 이전 설정을 유지하며 종료 확인 생략도 적용하지 않는다.

규칙 카드는 제목과 켜짐/꺼짐 스위치를 위쪽에 둔다. 조건·이동 위치·실행 조건을 가운데에 표시한다. 아래 오른쪽에는 ‘편집’ 보조 버튼과 ‘검사 및 실행’ 강조 버튼을 나란히 둔다. 꺼진 규칙도 편집할 수 있지만 검사 버튼은 비활성이다. 스위치는 색 외에 글자와 손잡이 위치로 상태를 표시하며 Tab·Space, 포커스 테두리, 접근 가능한 이름과 토글 상태를 제공한다. 스위치를 켜는 것만으로 파일을 옮기지 않는다.

## 폴더 복제와 실행 조건

검사 폴더 항목의 복제 아이콘은 이름·경로·제외 폴더·폴더 실행 조건과 모든 규칙을 미리 채운 복제 창을 연다. 새 검사 위치를 정하고 ‘복제’를 눌러야 저장한다. 겹치는 검사 범위는 기존 기준대로 거부한다. 원본 폴더와 규칙은 변경하지 않으며 새 ID를 부여한다. 목적지는 그대로 복제하고 제외 경로는 새 검사 위치 안의 같은 상대 경로로 바꾼다. 제거 버튼은 복제 창에 표시하지 않는다.

폴더 실행 조건은 수동·프로그램 시작·프로그램 종료를 제공한다. 프로그램 선택은 Windows 기본 .exe 선택 창을 사용한다. 폴더 조건은 켜진 규칙 전체를 한 검사 목록으로 만든다. 규칙 자체의 실행 조건은 독립적인 추가 경로다. 같은 이벤트에 두 경로가 겹치면 한 번만 포함한다. 폴더 목록은 쪼개지 않고 규칙 순서를 유지하며, 겹친 조건 중 확인이 필요하면 전체 목록을 확인 후 실행한다. 꺼진 규칙은 제외한다. 메인 본문에 현재 폴더 조건을 표시한다.

## 프로그램 감지 권한과 대체 감지

WMI 등록 실패는 전체 감지 중단으로 끝내지 않고 250ms 간격 확인으로 전환한다. 등록 단계·오류 코드·전환 사실을 기록한다. 처음부터 실행 중인 프로그램은 새 시작으로 표시하지 않는다. 같은 경로의 첫 실행본과 마지막 종료만 알린다. 경로 접근 실패·불완전한 표본을 종료로 추측하지 않는다. 초기 미확인이 나중에 해소되어도 거짓 시작을 만들지 않는다. 대체 방식의 짧은 실행 누락 가능성을 안내한다.

프로그램 선택은 현재 Windows 기본 .exe 선택 창이다. 설치된 앱 목록을 선택하는 별도 UI는 아직 구현하지 않았다. 앱 등록 정보·파일 연결 목록과 실제 감지 대상 EXE의 매핑은 별도 기능으로 다룬다.

## 탐색기 단축 등록

시작 시 메뉴 자동 확인은 기본 켜짐이다. 설정에서 끄고 저장할 수 있다. 메뉴 해제는 자동 등록을 끄고 즉시 저장하며 설정 취소로 되살리지 않는다. 이미 같은 EXE에 등록되어 있으면 재등록하지 않는다. 설정의 탐색기 연동은 현재 사용자 메뉴 등록·경로 갱신·해제를 제공한다. 이 버튼들은 즉시 적용된다. 실행 파일 이동 후 갱신 안내와 Windows 11의 ‘더 많은 옵션 표시’ 가능성을 설명한다.

‘차곡에 추가’ 요청은 우클릭한 폴더를 이동 목적지로 채운 시작 창을 연다. 사용자는 목적지를 다시 선택하고, 기존 검사 폴더를 선택하거나 새 검사 폴더를 등록할 수 있다. 다음에는 기존 규칙 편집 창을 사용한다. 실제 이동은 기존 검사·실행 흐름을 따른다. 새 검사 폴더 등록은 별도 저장임을 표시한다.

이미 실행 중이면 같은 사용자·세션의 기존 앱에 요청을 전달한다. 작업·다른 편집 창 사용 중에는 최대 20개를 대기하며 새 요청으로 현재 이동을 중단하지 않는다. 종료 중에는 새 요청을 거부한다. 요청 전달 실패나 과다 요청을 사용자에게 알린다. 메뉴가 등록된 EXE를 옮기면 설정에서 경로를 갱신한다.

Windows 11 첫 메뉴는 별도 네이티브 DLL·개발용 sparse package로 테스트한다. x64 Windows 11의 개발자 모드가 켜져 있을 때만 자동·수동 등록하고, 개발자 모드나 인증서 신뢰 설정은 바꾸지 않는다. 일반 배포에는 서명 패키지가 필요함을 표시한다. 등록 중에는 진행 상태를 표시하고 설정 입력·닫기를 잠근다. 개별 Windows 등록 명령의 대기 시간은 30초로 제한한다. 기존 메뉴가 가능하면 유지하며 실패를 숨기지 않는다. 확장 리소스 캐시는 검사에서 제외한다.

## 검사·실행 상태

| 상태 | 제목·정보 | 진행 표시 | 결과 의미 |
|---|---|---|---|
| 검사 중 | 폴더 검사 중, 파일을 이동하지 않는다는 설명 | 전체 개수를 모르면 불확정 표시 | 이동 시작 아님 |
| 검사 완료 | 대상·실행 가능·경고 개수, 실행 대상 확인 안내 | 실행 진행 막대는 숨김 | 실행 버튼을 눌러야 이동 |
| 실행 중 | 처리 개수/전체 개수, 경과 시간, 현재 파일·작업 단계 | 전체는 파일 처리 기준, 현재 파일은 복사 바이트 기준 | 복사 100%와 최종 이동 완료를 구분 |
| 정상 완료 | ‘파일 정리를 완료했습니다’, 결과별 개수와 소요 시간 | 실제 처리 비율과 체크 표시 | 선택한 모든 항목이 완료된 경우 |
| 확인 필요 | ‘일부 항목 확인 필요’, 보류·실패·원본 보존 등 | 실제 처리 비율과 주의 표시 | 처리 100%도 성공 100%는 아님 |
| 취소 | 취소 안내, 취소된 시도와 미실행 개수 | 완료된 처리 비율에서 정지 | 완료된 이동을 되돌린다는 의미 아님 |
| 오류 중단 | 오류 안내와 이유, 이미 처리된 개수 | 실제 처리 비율에서 정지 | 남은 이동을 중단하고 기록 확인 |

검증·이동 위치 확정 단계는 측정하지 않은 시간 비율을 만들어 표시하지 않는다. 복사 진행은 실제 읽고 쓴 바이트를 기준으로 표시한다. 진행 알림은 복사 중 약 100ms 간격으로 제한한다. 이전 파일에서 늦게 도착한 알림이 다음 파일이나 완료 화면을 덮지 않게 한다.

## 완료 결과

요약 개수는 이번 선택 항목 기준이며 완료 수와 0이 아닌 나머지 결과 수를 표시한다. 완료 카드는 같은 화면에 남고 ‘실행 기록 보기’를 제공한다. 성공·주의·오류 색은 테마별 의미 색을 사용하며 제목·아이콘·숫자를 함께 표시한다. 완료 시 한 번의 짧은 투명도 강조를 사용할 수 있다. 반복 점멸·화면 전체 효과·입력을 막는 애니메이션은 사용하지 않는다. Windows 애니메이션이 꺼지면 효과 없이 최종 상태를 표시한다.

목록에는 ‘처리 결과’ 열을 둔다. 대기·완료·보류·실패·원본 보존·취소·건너뜀·미실행·제외·미확인을 구분하고 이유를 표시한다. 긴 이유는 툴팁과 실행 기록으로 확인한다. 실행 결과는 디스크에 저장해 페이지를 바꿔도 유지한다. 결과 저장 오류가 있으면 실제로 이동했지만 결과만 없을 수 있다. 결과가 없는 행은 ‘미확인’으로 표시하고 파일 위치와 실행 기록을 확인하게 한다. 실행이 끝난 계획은 다시 실행할 수 없으며 새 검사가 필요하다.

취소된 항목은 실행을 시도했지만 취소된 항목이다. 미실행은 선택하지 않았거나 중단으로 아직 실행하지 않은 항목이다. 요약의 전체 개수는 이번에 선택한 실행 대상 기준이고, 목록의 미실행에는 선택하지 않은 행도 포함될 수 있다.

## 검증 범위

실제 Windows에서 기본·선택·포커스·비활성·작업 중·완료 상태를 라이트·다크·시스템, 100%·150%·200% 배율로 확인한다. 키보드로 콤보 박스·페이지 이동·실행·취소를 사용할 수 있어야 한다. 긴 파일명과 긴 오류 메시지가 버튼을 밀어내지 않아야 한다. 기본 진행 컨트롤에 접근 가능한 이름을 부여하고, 결과는 색이나 움직임 없이도 이해할 수 있어야 한다.

macOS에서 확인할 수 없는 실제 WPF 표시, 애니메이션, 보조 기술 알림은 미검증으로 남긴다.

## 0.2.2 표시·감지 회귀 기준

객체를 표시하는 ComboBox는 선택 영역에도 ItemTemplateSelector와 SelectionBoxItemStringFormat을 전달한다. DisplayMemberPath로 지정한 이름이 펼친 목록과 선택 영역에 모두 보여야 한다. 전체 경로는 보조 정보이며 내부 타입명을 대신하는 표시 수단으로 쓰지 않는다.

대체 감지는 이전·현재 표본의 경로뿐 아니라 PID를 비교한다. 같은 경로라도 살아남은 실행본이 없으면 종료·재시작으로 구분한다. 일부 실행본이 계속 살아 있으면 첫 실행·마지막 종료 기준을 유지한다. 250ms는 타이머 간격이며 실행 시간이나 OS 부하를 포함한 보장 지연 시간이 아니다. 표본 사이에 끝나는 실행, 표본에서 관측되지 않은 PID 재사용은 완전히 식별할 수 없다.

감지 기록은 이벤트 수신과 실제 파일 이동을 구분한다. 편집 창·현재 작업·확인 목록 때문에 대기하는 요청은 그 이유를 남긴다. 기존 대기 요청과 통합되어도 추가 실행으로 기록하지 않는다.

## 0.3.0 터미널 인터페이스

TUI는 폴더→규칙→대상→결과로 이동한다. 선택 항목은 >와 대비되는 배경으로 표시한다. 화면 높이에 맞춰 목록을 나누되 100건 페이지의 모든 행에 접근할 수 있어야 한다. I는 전체 경로·판단·결과를 표시한다. 터미널 입력의 제어 문자는 화면 명령으로 실행하지 않는다.

TUI의 설정 저장·규칙 토글은 파일 이동과 구분한다. 실행 전 전체 선택 수·교체 수를 확인한다. 터미널 색은 호스트 기본색을 따르며 GUI 테마 설정은 다음 GUI 실행에 반영한다. GUI·CLI·TUI 중 하나만 사용하며 다른 클라이언트의 실행 중 계획을 가져오거나 프로세스를 강제 종료하지 않는다.

## 0.4.0 터미널 대시보드

폴더·규칙을 한 화면에 나란히 표시하고 Tab으로 현재 영역을 전환한다. 선택 규칙 조건과 목적지를 고정 표시한다. 80열 미만은 선택 영역만 표시한다. 권장 크기는 80열×24줄이다. 미리보기는 선택/파일/처리/목적지 표로 표시하고 디스크 페이지 선택을 유지한다. 결과 목록에도 완료·부분 처리 요약을 남긴다. 파일 수 진행률과 개별 파일의 복사 단계·바이트를 구분한다. 색 없이도 >와 ▶ 및 상태 글자로 선택을 식별한다.

## 0.4.1 TUI 저장·실행 구분

상단 심볼은 문자로 그린 겹친 폴더와 이동 경로로 표시하고 강제로 기다리는 시작 효과를 넣지 않는다. F는 폴더 추가, N은 선택 폴더의 규칙 추가다. 저장 성공한 ID를 최신 설정에서 다시 찾아 선택하고 표시 범위를 이동한다. 저장 완료·규칙 개수를 표시한다. 취소·저장 실패 시 새 항목을 선택했다고 표시하지 않는다. R은 영역과 무관하게 선택 규칙 검사, A는 폴더 전체 검사다. 미리보기 상단에 선택 규칙 이름 또는 폴더 전체 범위를 표시한다.

## 0.4.2 블록 배너

TUI 로고는 가는 외곽선 대신 █/▀/▄로 채운 심볼과 CHAGOK 픽셀 글자다. 5줄 고정 배너와 1줄 상태를 사용하고 60×24에서도 실행 안내가 남도록 목록 높이를 계산한다. 심볼은 청록, 글자는 파랑이며 밝은 콘솔 배경에서는 어두운 색을 쓴다. 본문과 작업 결과의 글자색을 바꾸지 않는다. NO_COLOR와 리디렉션 출력에서는 배너 색을 적용하지 않는다.

## 0.4.3 TUI 표현·규칙 문맥

심볼과 이름의 색을 청록으로 통일하고 글자 획을 굵게 맞춘다. 80열 미만에서는 이름만 표시한다. 규칙 추가·편집 시작과 저장 확인에 검사 폴더의 이름·전체 경로를 표시한다. R 이 규칙만 검사 및 실행 / A 폴더 전체 검사 및 실행을 별도 줄로 구분하고 이동 전 확인을 유지한다.

## 0.4.4 입력 취소

TUI 모든 입력 폼은 Esc 및 /cancel + Enter로 저장하지 않고 목록에 복귀한다. Ctrl+C 앱 종료와 구분하고 취소 상태를 표시한다. 저장 전 작업 객체만 수정하고, 취소 시 기존 설정·선택을 유지한다. 입력은 한글·문자 폭·커서 이동·삭제·긴 경로 가로 이동을 고려한다.

## 0.5.0 문자 심볼·패널·기능 설명

CHAGOK 글자는 유지하고 심볼을 더 촘촘한 점 문자로 표현한다. 심볼 청록·글자 파랑을 구분하며 NO_COLOR를 유지한다. 테두리와 제목·선택 표시로 폴더/규칙/조건·이동/검사 결과를 구분한다. 색 없이도 >와 제목으로 선택을 식별한다. 60×24에서도 실행과 도움말 안내를 보인다.

F1/?로 메인·미리보기의 문맥에 맞는 기능 설명을 연다. ←→ 기능·↑↓ 설명 스크롤·Esc 복귀다. 도움말은 설정이나 파일을 바꾸지 않고 미리보기 선택을 보존한다. GUI 스타일과 파일 이동 안전 정책은 유지한다.


## 0.5.1 TUI 선택 범위

- 선택 배경은 현재 조작 중인 패널의 내용 칸 안에서 끝나야 한다. 테두리·좌우 간격·반대 패널에 번지지 않는다.
- 반대쪽 선택은 ·와 글자색으로 유지한다. 이름에 >가 있어도 강조하지 않는다. 좁은 창/긴 한글 이름/NO_COLOR/미리보기도 확인한다.


## 0.5.2 TUI 워드마크

- 승인된 D안의 도트 매트릭스 CHAGOK. 청록 심볼/파랑 이름, 5줄 높이, 80열 미만에서는 심볼 생략. NO_COLOR와 배너 뒤 색 복원 유지.


## 0.5.3 TUI 상세보기

- I는 현재 영역에 따라 폴더/규칙 상세를 표시한다. 일반 오류 Notice로 상세를 출력하지 않는다.
- 항목 이름과 값을 분리하고 긴 경로를 셀 폭 기준으로 줄바꿈한다. 스크롤·목록 복귀 뒤 설정과 선택을 보존한다.


## 0.5.4 TUI 입력 화면

- 폴더/규칙 폼은 같은 테두리·섹션을 사용하고 입력 단계마다 다시 그린다. 현재 값·번호 선택지·검사 폴더 문맥·최근 입력을 표시한다.
- 저장 전 전체 내용 스크롤과 Y 저장/취소를 유지한다. 폼 입력은 지정 행 안에서 편집하되 커서 위치 조회에 의존하지 않는다. 긴 경로·한글·Esc/취소/Enter 기존 값 보존을 실제 PTY로 확인한다.


## 0.5.5 선택형 설정

- 설정은 네 항목을 한 화면에 표시하고 원하는 항목을 바로 선택한다. 변경 값은 임시 복사본에만 반영, S 저장과 Esc 취소를 구분한다.
- ↑↓/Tab/1~4 선택, ←→/Enter/Space 변경. 선택 설명·미저장 표시·도움말 왕복·60열 화면·저장 실패 시 재시도를 확인한다. GUI 전용 설정과 TUI 팔레트/실제 탐색기 등록을 구분한다.


## 0.5.6 폴더·규칙 목록형 폼

- 폴더/규칙/복제 폼은 항목을 직접 선택한다. 조건상 비활성인 항목은 값을 보존하고 편집을 막는다.
- 입력창 취소와 전체 폼 취소를 구분한다. S 검토 후 Y 저장, 검토 취소/저장 검증 실패는 초안을 유지한다.
- 경로 변경 시 제외 폴더 재배치는 현재 편집 경로를 기준으로 수행한다. 항목 수정 순서와 관계없이 복제/ID/규칙/검사 안전성을 유지한다.
- 작은 창 선택 행 자동 스크롤·I 전체 값·다른 항목 우선 편집·설정 보존을 실제 PTY로 확인한다.

## 0.5.7 이동 위치 도우미

검사 폴더 추가/편집의 체크박스로 최근 이동 위치 표시·기록을 제어한다. 기본은 꺼짐이다. 같은 폴더에서 규칙 저장에 성공한 기본 위치만 최근 10개까지 최신순·중복 없이 보관한다. 끄면 목록을 숨기고 새 기록을 중단하되 기존 기록은 보존한다. 취소·저장 실패·실행만으로는 기록하지 않는다. 복제 시 다른 설정처럼 복사하되 이후 기록은 폴더별로 분리한다.

규칙 이름 아래 ‘이동할 폴더 뒤에 규칙명 폴더 추가’ 체크박스를 둔다. 기본 위치 입력·Windows 폴더 선택·최근 위치 선택은 기본 위치만 바꾼다. 최종 경로는 규칙명 또는 기본 위치 변경 즉시 표시한다. 옵션을 켜면 자동 생성 체크박스를 켜진 비활성 상태로 표시한다. 옵션을 끄면 이전 자동 생성 선택값으로 복원한다. 규칙명으로 폴더를 만들 수 없는 경우 경로 미리보기에 이유를 표시하고 저장을 거부한다. 실제 폴더 생성은 실행 단계에서만 수행한다.

TUI는 기존 항목 번호를 유지하고 규칙 목록 끝에 이동 위치 도우미를 추가한다. 최근 위치는 ←→/Enter, 최종 경로는 I로 확인한다. 빈 최근 목록은 선택할 수 없다. 최종 경로를 규칙 카드·대시보드·상세·검사·자동 제외·실행에 일관되게 사용한다.

## 0.5.8 기본 위치와 최종 경로 표시

새 규칙에는 최근 위치 표시가 켜진 검사 폴더의 가장 최근 기본 이동 위치를 미리 채운다. 기존 규칙 편집은 저장된 기본 위치를 유지한다. 탐색기에서 전달한 명시 목적지는 최근 위치보다 우선한다. 최근 위치 콤보박스는 유지하며, 초기값을 불러오는 것만으로 최근 기록이나 설정을 변경하지 않는다.

GUI 옵션 명칭은 ‘규칙명 폴더 사용’이다. 켜면 ‘이동할 폴더’ 입력칸에 최종 경로를 표시하고 읽기 전용으로 둔다. 바로 아래 ‘기본 위치’ 입력칸을 표시해 직접 경로를 바꿀 수 있게 한다. 찾아보기와 최근 위치 선택도 기본 위치에 적용한다. 이름 변경·옵션 켜기/끄기·위치 변경은 즉시 반영하며, 저장은 기본 위치만 보관한다. 옵션을 끄면 주 입력칸을 기본 위치 편집용으로 돌린다. 표시 문자열을 다시 기본 경로로 저장하거나 규칙명을 반복해 붙이지 않는다.

TUI는 폴더 7개·규칙 15개 항목의 기능·연계 옵션을 선택 아래 설명한다. 설명이 긴 경우 I로 전체 값과 설명을 스크롤해 읽는다. 비활성 이유는 파일명 제한 없음/수동 실행/최근 위치 꺼짐 또는 비어 있음/규칙명 폴더 사용으로 구분한다. 강제 자동 생성은 ‘사용 안 함’ 대신 ‘켜짐 · 자동 적용’이다. 조회 전용 항목을 Enter로 열어도 값을 수정한 것으로 표시하지 않는다.

## 0.6.0 파일명 분석

승인한 시안의 왼쪽 등록 폴더/본문 구분값 목록/오른쪽 파일 목록 구성을 따른다. 왼쪽 ‘등록 폴더 분석’과 규칙 화면 ‘파일명 분석’으로 접근한다. 폴더 카드에 패턴 일치 파일 수·전체 그룹 수·경고를 표시한다. 필터가 걸려도 요약의 전체 그룹 수와 목록의 표시 그룹 수를 구분한다. 분석 조건·시점·일부 생략을 함께 표시하며 작업 중 진행과 취소를 제공한다.

기본 분석은 []/하위 폴더 제외다. ()/{} 및 하위 폴더 포함을 선택할 수 있다. ‘2개 이상만 보기’는 결과 필터로 재분석 없이 바뀐다. 괄호·재귀 옵션 변경은 다시 분석해야 적용되며 이전 결과의 실제 조건을 명시한다. 그룹/파일은 100개씩, 개수 내림차순·같은 개수는 구분값 순으로 표시한다. 파일을 두 번 누르면 전체 경로를 보여준다. SQL 저장소 실패를 부분 성공으로 표시하지 않는다.

대소문자·공백을 구분하고 같은 파일의 같은 값은 한 번 센다. 여러 값이 있으면 각 그룹에 포함하므로 그룹의 파일 수 합계와 패턴 일치 파일 수가 다를 수 있다. 빈/중첩 괄호는 제외한다. 제외 경로·최종 목적지·차곡 저장소·링크는 기존 검사 안전 기준을 따른다. 읽을 수 없는 경로는 경고이며 0개 확정으로 해석하지 않는다.

분석에서 규칙 만들기는 NameMatch.Group과 선택 괄호 구분값을 채운 초안만 연다. 최근 기본 위치·직접 항목 편집·저장 취소·파일 실행 확인을 재사용한다. 일반 ‘포함’으로 변환하여 대소문자/중첩 일치 범위를 넓히지 않는다. 전체 실행은 기존 첫 일치 규칙 우선순위를 유지한다.

분석은 파일/설정/실행 기록을 수정하지 않는다. 원본 이름과 집계는 임시 SQLite, 폴더 순회는 기존 디스크 순회/임대를 재사용한다. 현재 결과 하나만 유지하고 재분석·규칙/폴더 설정 변경·이동 검사·정상 종료 시 정리한다. 트레이 숨기기·테마 변경만으로 현재 분석을 지우지 않는다. 외부 변경을 자동 감시하지 않는 분석 시점 스냅샷이다.

TUI P로 같은 엔진을 열며 넓은 창은 폴더/그룹/파일 세 영역, 좁은 창은 현재 영역을 표시한다. Tab/←→ 전환, ↑↓ 선택, N/P 페이지, I 전체 값, W 경고, M 필터, B 괄호, S 재귀, R 재분석, C 규칙 초안, Esc 복귀다. 분석 중 Ctrl+C는 앱 취소이며 파일 이동은 없다.

### 0.6.0 추가 수정 · 직접 경로와 분류 정규식

0.5.8의 읽기 전용 최종 경로/별도 기본 위치 입력 정책을 대체한다. 주 ‘이동할 폴더’는 항상 편집 가능하며 기본 위치 입력칸은 없앤다. 규칙명 옵션이 켜졌을 때 직접 입력 경로 끝이 규칙명과 같으면 그 한 개를 관리하는 접미 폴더로 인식한다. 없으면 입력 완료 시 규칙명을 추가한다. 입력 중 매 글자마다 경로를 다시 쓰지 않는다. 이름·체크박스 변경, 찾아보기·최근 위치는 최종 경로를 갱신하며 저장·최근 기록은 부모 경로를 보관한다. 잘못된 경로/규칙명 오류 문자열을 경로 입력값에 넣지 않는다.

기존 괄호 종류 선택에 ‘직접 입력 (정규식)’을 추가한다. 입력 방법 버튼/툴팁, 시험 파일명, 추출 구분값 미리보기를 함께 둔다. 정규식은 .NET 문법, 확장자 포함 파일명 대상이며 `(?<group>...)`의 모든 캡처 또는 전체 일치 값을 집계한다. 빈 값 제외, 파일당 동일 값 1회, 구분값은 ordinal 비교다. `(?i)`는 매칭만 바꾸고 그룹 합산/규칙의 구분값 비교는 바꾸지 않는다. 최대 2,000자·파일당 100ms 제한. 잘못된 식은 분석 시작 전에 안내한다. 시간 초과는 부분 성공으로 삼지 않고 중단·캐시 정리한다.

TUI E에서 같은 직접 선택형 폼을 연다. 정규식/시험 파일명/미리보기 항목, I 전체 설명, S 검토·Y 적용, Esc 취소를 제공한다. B는 괄호 기본 모드로 돌아간다. CLI --regex와 규칙 --group-expression도 같은 기준이다. GroupExpression이 빈 기존 Group 규칙은 괄호 기준을 유지한다. 사용자 정규식으로 만든 규칙은 Pattern에 선택 구분값을, GroupExpression에 식을 보관하며 두 값 모두 검토 화면에 표시한다.

### 0.6.0 입력 도움말 가독성 보완

분류 정규식 도움말을 작은 기본 MessageBox 대신 앱 테마의 전용 창으로 연다. 제목/짧은 안내/번호별 예시 카드/고정 닫기 버튼을 나눈다. 각 카드는 정규식·시험 파일명·추출 그룹·이 예시 사용 버튼을 제공한다. 괄호 포함/내부 값/밑줄 접두사/연도 네 예시를 구분한다. 기호와 제한은 접힌 고급 설명에 둔다. 예시 선택은 입력과 시험 파일명만 채우고 재분석·파일 이동을 수행하지 않는다. 큰 글자·줄 간격·테마 리소스·작은 창 스크롤·Esc 닫기·키보드 접근·코드 복사를 유지한다.

### 0.6.0 입력 방법 안에서 직접 연습

각 예시 카드의 직접 연습 버튼으로 파일명 여러 줄·수정 가능한 정규식·연습 결과 보기·결과 표·그룹별 개수를 펼친다. 한 줄을 파일 하나로 가정하며 최대 10줄/4,000자, 식 2,000자/파일당 100ms 제한이다. 파일명은 경로를 뺀 이름과 확장자라고 안내하고, 처음에는 식을 그대로 두고 파일명부터 바꾸도록 예시별 연습 과제를 제공한다. 실제 파일/설정/분석 DB를 건드리지 않는다.

결과 표는 파일명/찾은 부분/그룹 이름을 나눈다. 미일치와 빈 그룹을 구분하고, 한 줄에서 같은 그룹은 한 번만 센다. 공통 FilenameGroups 추출 경로로 전체 일치 문자열과 구분값을 얻어 분석과 연습의 기준이 달라지지 않게 한다. 입력 변경 시 오래된 결과를 숨긴다. 실행 중 입력/적용을 잠그고 백그라운드에서 계산하며 결과 적용 뒤 복원한다. 정규식 Enter는 창 닫기가 아니라 연습 실행이다. 원하는 결과 뒤 카드 아래 연습한 식 사용으로 현재 식과 첫 번째 파일명을 분석 화면에 채우며 재분석/파일 이동은 하지 않는다.
